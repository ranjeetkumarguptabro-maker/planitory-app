# Planitory - Maps with stories. Trips with meaning.

Planitory is a mobile-first travel web application that connects travelers with curated travel maps, hidden gems, and itineraries crafted by creators worldwide.

---

## ✨ Features & Screens (12 Complete Flows)

1. **Page 1: Welcome & Sign-In (`c1.png`)** &mdash; Hero scenery, Google, Phone, and Email authentication options, terms & privacy modals.
2. **Page 2: Phone Verification (`c2.png`)** &mdash; Phone number entry with country code selector and interactive 4-digit OTP modal.
3. **Page 3: Region Selection (`c4.png`)** &mdash; Onboarding Step 1/3: Europe, Asia, Americas, Local, Anywhere.
4. **Page 4: Place Preferences (`c3.png`)** &mdash; Onboarding Step 2/3: 3×3 interactive category grid.
5. **Page 5: Travel Goals (`c5.png`)** &mdash; Onboarding Step 3/3: Exploration and adventure goals.
6. **Page 6: Explore Feed (`c6.png`)** &mdash; Search bar, category filters, featured Paris hero map, popular maps carousel, featured travelers, and 5-tab bottom navigation.
7. **Page 7: Map Detail (`c7.png`)** &mdash; "Best 5 Cafés in Paris" detail page with cover photo, review score, feature badges, tabs (Overview, Inside, Reviews, Creator), image lightbox, and Buy Now checkout trigger.
8. **Page 8: Checkout & Payment (`c8.png`)** &mdash; Interactive payment method selector (Credit Card with auto brand detection, PayPal, Apple Pay) and payment confirmation.
9. **Page 9: Purchased Map View (`c10.png`)** &mdash; Post-purchase "Paris Essentials" interactive map with category filters, pin hotspots, and theme customization modal.
10. **Page 10: Creators Feed (`c12.png`)** &mdash; Curated travel creators list with follow toggles, bios, photo galleries, and image lightbox.
11. **Page 11: Creator Profile (`c13.png`)** &mdash; Emma Wilson's creator profile with cover panorama, followers, social links, and 2×2 map card grid.
12. **Page 12: User Profile (`c14.png`)** &mdash; Alex Parker's profile with cover banner, avatar editing, 4 stats cards, segmented tabs (My Maps, Favorites, Saved Places, Activity), and rich map cards.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ranjeetkumarguptabro-maker/planitory-app.git

# Navigate into the project
cd planitory-app

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

When viewing on desktop, a top control bar allows switching between:

- **Fitted Mode** (responsive container)
